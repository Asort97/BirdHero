## 📖 О проекте

**BirdHero** (BirdStick) — это динамичная аркадная игра для мобильных устройств, разработанная на Unity. Игрок управляет птичкой, которая должна точно приземляться на движущиеся платформы различного размера. Чем точнее приземление, тем больше очков!

### 🎮 Геймплей
- **Точные прыжки**: Приземляйтесь в центр круга для максимальных очков
- **Процедурная генерация**: Бесконечная игра с динамически создаваемыми платформами
- **Система скинов**: Разблокируйте новых персонажей из яиц
- **Система заданий**: Выполняйте задания для прогресса
- **Рекорды**: Отслеживайте свои лучшие результаты

## ✨ Особенности

### Игровая механика
- ✅ **Динамический геймплей**: Процедурная генерация уровней с изменяющимся размером платформ
- ✅ **Система точности**: Оценка приземления (точное/неточное попадание)
- ✅ **Физика**: Реалистичное движение птички с использованием Rigidbody2D
- ✅ **Анимации**: Плавные анимации крыльев и движения

- ✅ **Адаптивный интерфейс**: Оптимизирован для различных разрешений экранов
- ✅ **Анимированное меню**: Плавные переходы и эффекты с DOTween
- ✅ **Система пауз**: Удобное меню паузы в игре
- ✅ **Визуальные эффекты**: Эффекты освещения и частиц

### Системы менеджмента
- ✅ **ScoreManager**: Управление очками, рекордами и статистикой
- ✅ **LevelGenerator**: Динамическая генерация игровых объектов
- ✅ **SkinManager**: Система разблокировки и выбора персонажей
- ✅ **TaskManager**: Система заданий и прогрессии
- ✅ **CameraManager**: Управление камерой и следованием за игроком

### Сохранение данных
- ✅ **PlayerPrefs**: Локальное хранение прогресса, рекордов и разблокированных скинов

## 🏗 Архитектура

### Паттерны проектирования

#### 1. **Event-Driven Architecture**
Использование статических событий (Actions) для слабосвязанной коммуникации между компонентами:

```csharp
// BirdController.cs
public static Action OnStartGame;
public static Action OnJumped;
public static Action OnDead;

// LevelGenerator.cs подписывается на события
BirdController.OnJumped += GenerateNext;
BirdController.OnDead += GenerateStart;
```

#### 2. **Singleton Pattern**
Менеджеры используют паттерн Singleton для глобального доступа

#### 3. **Object Pooling**
Эффективное переиспользование игровых объектов

### Структура проекта

```
BirdHero/
├── Assets/
│   ├── Scripts/                 # Игровая логика
│   │   ├── BirdController.cs    # Управление птичкой
│   │   ├── LevelGenerator.cs    # Генерация уровней
│   │   ├── ScoreManager.cs      # Система очков
│   │   ├── SkinManager.cs       # Управление скинами
│   │   ├── MenuManager.cs       # UI менеджер
│   │   └── Tasks/               # Система заданий
│   ├── Scenes/                  # Сцены Unity
│   │   ├── Menu.unity           # Главное меню
│   │   └── Gameplay.unity       # Игровая сцена
│   ├── Sprites/                 # 2D графика
│   ├── Prefabs/                 # Префабы
│   ├── Anims/                   # Анимации
│   └── Plugins/                 # Внешние плагины
│       └── Demigiant/DOTween/   # DOTween библиотека
├── ProjectSettings/             # Настройки Unity
└── Packages/                    # Unity Package Manager
```

### Ключевые компоненты

#### 🎯 BirdController
Основной контроллер персонажа, управляющий:
- Физикой движения

## 🚀 Установка

### Требования
- Unity 2021.2.12f1 или выше
- Visual Studio 2019/2022 или JetBrains Rider
- Android SDK (для Android сборки)
- Xcode (для iOS сборки, только macOS)

### Шаги установки

1. **Клонируйте репозиторий**
```bash
git clone https://github.com/Asort97/BirdHero.git
cd BirdHero
```

2. **Откройте проект в Unity Hub**
- Запустите Unity Hub
- Нажмите "Add" и выберите папку проекта
- Убедитесь, что установлена версия Unity 2021.2.12f1

3. **Откройте проект**
- Выберите проект в Unity Hub
- Дождитесь импорта всех ассетов

4. **Настройка DOTween (если требуется)**
- После первого открытия проекта может появиться окно настройки DOTween
- Следуйте инструкциям мастера установки

### Запуск проекта

1. Откройте сцену `Assets/Scenes/Menu.unity`
2. Нажмите кнопку Play в редакторе Unity
3. Для тестирования на устройстве:
   - **Android**: File → Build Settings → Android → Build and Run
   - **iOS**: File → Build Settings → iOS → Build (требуется Xcode)
